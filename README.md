# AWT
# Turbina Eólica Vertical Darrieus — Cabo de Santa Marta (SC)

Repositório de apoio ao projeto de ensino-pesquisa-extensão da disciplina **Energia Eólica I (EES7470)**, do curso de Engenharia de Energia da UFSC Araranguá, cujo objetivo é propor, dimensionar e fabricar (via impressão 3D) uma turbina eólica de eixo vertical, tipo Darrieus, para instalação em contexto residencial na região do Cabo de Santa Marta, Santa Catarina, Brasil.

O trabalho é conduzido segundo a metodologia **PBL (Project/Problem-Based Learning)** integrada à abordagem **SHES (Sustainable Human and Environmental Systems)**, articulando fundamentação teórica de recurso eólico, cálculo de potencial energético, dimensionamento paramétrico do rotor e modelagem 3D para manufatura.
